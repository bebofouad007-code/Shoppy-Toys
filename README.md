## Project Name
Shoppy Toys

## Project Idea
Shoppy Toys is a digital marketing project for an online toy store that helps parents choose age-appropriate toys supporting children's learning, creativity, and development. The project aims to build brand awareness and reach potential customers through a website and social media content.
